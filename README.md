# Supplier Scout

Рабочий прототип для поиска и сравнения поставщиков продуктов для HoReCa. Демосценарий — закупка кофе в зернах в Екатеринбурге.

## Что умеет

- показывает 10 реальных поставщиков с официальными источниками;
- фильтрует по доставке, опубликованной цене и соответствию MOQ;
- объясняет рейтинг до отдельных критериев и подтверждающих фрагментов;
- сравнивает до трёх поставщиков и формирует текст запроса коммерческого предложения;
- экспортирует shortlist в CSV;
- продолжает работать из статического снимка, если API недоступен.

Снимок проверен 20 сентября 2026 года. Коммерческие условия меняются: перед закупкой их нужно подтвердить у поставщика.

## Быстрый старт

```powershell
npm.cmd install
npm.cmd run dev
```

Frontend откроется на `http://localhost:5173`. Без backend он автоматически использует `data/suppliers.json`.

Backend:

```powershell
cd backend
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

API: `http://127.0.0.1:8000/docs`.

Для подключения публичного frontend к размещённому API задайте repository variable `VITE_API_BASE_URL` (например, URL сервиса Render без завершающего `/`). Допустимые CORS-origin backend принимает из `SUPPLIER_SCOUT_CORS_ORIGINS` через запятую.

## Проверки

```powershell
npm.cmd test
npm.cmd run build
cd backend
python -m pytest
```

E2E-проверка обоих интерфейсов сама запускает production preview на портах 4173/4174 и использует установленный Chrome/Edge:

```powershell
npm.cmd run test:e2e
```

На Linux или при нестандартном расположении браузера задайте `CHROME_PATH`.

## Почему такой формат

Статический fallback делает ссылку на прототип надёжной для просмотра рекрутером. FastAPI + SQLite показывают рабочий API и модель данных, не превращая тестовое задание в инфраструктурный проект. Скоринг намеренно детерминирован: его можно проверить, обсудить с закупщиками и заменить после пилота.

## Как развивать

1. Интервью с закупщиками и фиксация реальных весов критериев.
2. Полуавтоматическое извлечение условий из страниц с обязательным human review.
3. История изменений и напоминания о повторной проверке.
4. Документы/сертификаты, тендерный контур и интеграция с ERP.
